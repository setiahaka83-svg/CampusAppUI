# CampusNote – Catatan Mahasiswa

## Deskripsi
CampusNote adalah aplikasi Android untuk membantu mahasiswa melihat dan mengelompokkan catatan perkuliahan. Aplikasi ini dibuat menggunakan Kotlin dan Jetpack Compose dengan desain antarmuka yang responsif.

## Fitur Aplikasi
- **Beranda:** Menampilkan sapaan dan daftar catatan terbaru.
- **Pencarian:** Mencari catatan berdasarkan judul atau subtitle.
- **Filter Kategori:** Memfilter catatan berdasarkan Kuliah, Praktikum, dan Tugas.
- **Detail Catatan:** Menampilkan kategori, tanggal, dan deskripsi catatan.
- **Jadwal Kuliah:** Menampilkan contoh agenda perkuliahan mingguan.
- **Profil Mahasiswa:** Menampilkan informasi profil contoh.
- **Menu Cepat:** Menyediakan pilihan Catatan, Tugas, dan Jadwal.
- **Dialog Interaktif:** Menampilkan simulasi tindakan dan notifikasi.
- **Desain Responsif:** Menggunakan navigasi bawah untuk layar ponsel dan navigation rail untuk layar yang lebih lebar.

## Teknologi
- Kotlin
- Android Studio
- Jetpack Compose
- Material Design 3

## Contoh Data
Aplikasi menyediakan contoh catatan:
1. Pemrograman Mobile
2. Basis Data
3. Struktur Data
4. Pemrograman Web

## Cara Menjalankan
1. Buka project melalui Android Studio.
2. Pastikan Android SDK dan dependensi Gradle sudah tersedia.
3. Tunggu proses sinkronisasi Gradle selesai.
4. Jalankan aplikasi menggunakan emulator atau perangkat Android.

## Catatan
Aplikasi ini masih berupa demonstrasi antarmuka (UI). Data catatan menggunakan data contoh yang ditulis di dalam kode dan belum disimpan ke database permanen.

## Pengembang
Project ini dikembangkan sebagai aplikasi pembelajaran dan demonstrasi antarmuka Android.
